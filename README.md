# Aesthesia Haven
A full-stack e-commerce platform built for a lifestyle and fashion brand. This application provides a seamless shopping experience with a focus on aesthetics, performance, and secure payment processing.

**Live Site:** [https://www.aesthesiahaven.com/](https://www.aesthesiahaven.com/)

<img width="1597" height="789" alt="image" src="https://github.com/user-attachments/assets/70997b94-2854-493c-8677-0e4bf69e3b0d" />

# Key Features
* **Responsive UI:** Fully responsive design built with React and Tailwind CSS, optimized for mobile shoppers.
* **Secure Payments:** Integrated **PayStack** for secure, real-time transaction processing.
* **Product Management:** Product fetching, filtering and categorization backed by MongoDB.
* **Shopping Cart:** Persistent cart state management for a smooth user experience.
* **Admin Dashboard:** Admin interface for managing orders and products.
* **Search Functionality:** Searching for products and collections

# Tech Stack
**Frontend:**
* React.js
* Tailwind CSS
* Axios

**Backend:**
* Node.js
* Express.js
* MongoDB & Mongoose
* Paystack API
